# 课堂演示提纲（约 8 分钟）

## 0:00—0:45 目标和技术栈
打开应用，说明使用 Vue 3、Vite、Tailwind CSS 4、localStorage；Agentic 指 Agent 执行实现、验证和交付，应用不调用大模型。

## 0:45—2:00 创建和查看
新建空标题，展示中文校验；输入“完成软件工程报告”并保持描述为空，创建成功。再创建“整理课堂演示材料”（进行中、中）和“搭建 Vue 项目骨架”（完成、低）。打开完整详情。对照截图 02—05。

## 2:00—3:15 编辑和删除
先修改标题后取消，证明数据不变；再为“完成软件工程报告”补充描述并设高优先级，标题保持可追踪。红高、黄中、绿低同时展示。新建一个“移除重复的演示草稿”，先取消删除，再确认删除。对照截图 06—10。

## 3:15—4:30 看板和状态
切到三列看板，拖动报告任务：待办→进行中→完成→待办。展示总数不变、可以拖入空列。解释手机/键盘可通过“编辑”修改状态。对照截图 11—12 和 round4.spec.js 的鼠标流程。

## 4:30—5:30 主题与持久化
切深色，打开表单，刷新仍为深色；再切浅色。确认任务状态、描述和优先级仍存在。说明数据只保存在当前浏览器/地址。对照截图 13—16、18。

## 5:30—6:45 提示词设计
打开 prompt-design.md，强调真实原始提示词、预先规定的五轮任务和 Agent 自主计划的区别。说明可观察验收、控制范围、失败不虚报、功能—测试—截图映射。

## 6:45—8:00 开发证据与交付
运行 `git log --oneline` 展示真实顺序提交；打开 development-log.md 的实际失败与修复。展示 `npm test`、`npm run test:e2e` 和 `npm run build` 的真实结果。打开截图索引与 acceptance.md。GitHub 完成后打开真实仓库；未完成时明确说远程交付待授权，不展示假链接。

演示准备：使用同一浏览器和固定端口；如需空白状态，用独立浏览器上下文，不清除用户已有任务。异常存储建议展示自动化测试日志和截图 21，不破坏日常任务。
